โปรดตั้งค่าหรืออัปเกรด AI Retro Game Translation Framework V3.2 ใน Codex จาก ZIP ที่แนบมาหรือจากพาธที่ฉันระบุ โดยทำทุกขั้นตอนผ่านแชต (ไม่ให้ฉันเปิด BAT หรือสร้างโฟลเดอร์เอง)

1) ตรวจหา Framework V3.1/V3.1.1, Skills, AGENTS.md และโปรเจกต์เดิมก่อนทำอะไร ห้ามลบ/เขียนทับโปรเจกต์ คำแปล ฐาน TM save file หรือ ROM ต้นฉบับ
2) ตรวจโครงสร้างและอ่าน AGENTS.md, README.md, docs/V3_2_REGRESSION_AND_RELEASE_TH.md จาก ZIP. ตรวจ ZIP ว่าไม่มีพาธหลุดโฟลเดอร์ก่อนแตกไฟล์
3) ติดตั้งหรืออัปเกรดด้วยเครื่องมือ Python ของ Framework ภายใต้สิทธิ์ที่ Codex มี; ขออนุญาตเมื่อจำเป็น ห้ามอ้างว่าติดตั้งสำเร็จหากยังไม่ได้ทำ
4) คง kompatibility กับ Skill `retro-game-th-v3-1` เดิม แต่ให้คำสั่ง "คู่มือ V3.2" เรียกระบบใหม่ได้ ตรวจ AGENTS/Skills/เครื่องมือจริง ไม่ติดตั้งสิ่งใดซ้ำโดยไม่จำเป็น
5) รัน `python -m unittest discover -s tests -p "test_*.py" -q` และ `python tools/install_once.py status` หลังตั้งค่า; ถ้าสิ่งแวดล้อมไม่อนุญาตให้ระบุ PENDING พร้อมวิธีแก้
6) ใช้ approved TM จากโครงการเก่าตามบริบท นำกลับมาใช้เฉพาะคำแปลที่ทบทวนแล้ว เก็บ binary/ฟอนต์และการทดสอบแยกตามเกม/เครื่อง
7) เมื่อเริ่มเกมใหม่หรือทำต่อ ให้ใช้ regression guard, delta quality queue, font review plan และ release preflight ตาม G0-G5 ก่อนเรียกว่าสมบูรณ์
8) ประหยัดโทเคน: อ่านเฉพาะ AGENTS และเอกสารที่เกี่ยวกับงานปัจจุบัน เก็บ checkpoint ถาวรและทำเฉพาะ delta ส่งรายงานสั้น ๆ ว่าทำอะไรสำเร็จและอะไรยัง PENDING

หลังตั้งค่าให้สรุปพาธที่ตั้งค่า, ผลตรวจจริง, ข้อจำกัด และตัวอย่างคำสั่ง "ใช้คู่มือ V3.2 แปลเกมนี้: <พาธ ROM>" โดยอย่าประดิษฐ์ผลทดสอบ
