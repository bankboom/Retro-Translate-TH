# Codex V3.2 — ใช้งานผ่านแชต ไม่ต้องเปิด BAT

1. โหลด ZIP และทำให้ Codex เข้าถึงได้ (แนบไฟล์หาก Codex รองรับไฟล์ หรือระบุพาธ ZIP ภายใน Codex workspace).
2. วางคำสั่งจาก `START_V3_2_CODEX_CHAT_TH.txt` ในแชต Codex. Codex อาจต้องขอสิทธิ์ให้เข้าถึงไฟล์และติดตั้ง Skill; ให้ผู้ใช้อนุมัติเฉพาะสิ่งจำเป็น.
3. เปิดแชตใหม่เมื่อ Codex แจ้งว่าตรวจ Skill, managed AGENTS และ framework แล้ว. ใช้ `ใช้คู่มือ V3.2 ...` พร้อมพาธ ROM.
4. Codex สร้าง/หาโฟลเดอร์โปรเจกต์โดยอัตโนมัติ; ไม่ขอให้ผู้ใช้รันไฟล์ `INSTALL_WINDOWS.bat` หรือสร้างโฟลเดอร์ด้วยตนเอง.

**อัปเกรดจาก V3.1 / V3.1.1:** ตัวติดตั้งรักษา managed block, ชื่อ Skill และโฟลเดอร์เดิมเพื่อใช้งานต่อและไม่แตะข้อมูล `~/RetroThaiProjects/projects/` ของผู้ใช้. เมื่อจะเปลี่ยนแปลง `~/.codex` ให้ Codex อธิบายและขออนุมัติตาม sandbox permission; หากไม่ได้รับสิทธิ์ ให้ใช้ V3.2 ภายใน workspace ที่เข้าถึงได้แทน. ROM ต้นฉบับอ่านอย่างเดียว.

หลักฐาน G0-G5 ต้องเก็บแยกจากการคาดเดา. `regression_guard.py` ยืนยันเฉพาะขอบเขตไบต์ ไม่ใช่ผลบูตหรือคุณภาพตัวอักษร. ห้ามอ้างว่าติดตั้งเสร็จ/เกมรันผ่านโดยไม่ตรวจจริง.
