# Codex Prompt — คุณภาพสูง ประหยัดโทเคน (คัดลอกไปใช้)

ทำงานกับโปรเจกต์ `projects/<SLUG>` เท่านั้น ตาม `AGENTS.md` ที่ root และในเกม พร้อมอ่าน `project_profile.json` และ `docs/NEXT_TASK.md` โดยไม่โหลดทั้ง repository.

**เป้าหมาย:** ไทยถูกความหมาย คงเนื้อเรื่อง/อารมณ์ตัวละครและระบบเกม ภาษาไทยถูกหลักไวยากรณ์ สระ/พยัญชนะ/วรรณยุกต์สวยงามและอ่านง่ายบนจอเกมจริง. อย่าแลกคุณภาพกับจำนวนโทเคน.

**วิธีทำ:** (1) สำรวจเฉพาะไฟล์/IDs ที่เปลี่ยนจากรอบก่อน (2) ใช้ approved glossary/TM และเครื่องมือ offline ก่อน (3) สร้าง `context_packet.md` ที่ `tools/token_saver.py pack` จำกัดไม่เกิน 40 rows หรือ 9,000 อักขระต่อชุด (4) แปล/ตรวจเฉพาะรายการที่ยังขาด พร้อมฉาก/ผู้พูดที่จำเป็น (5) ตรวจ placeholder, ตัวเลข, ชื่อ, ช่วงความยาว, semantic correctness ก่อนฉีดกลับ (6) ตรวจฟอนต์ทุกแบบที่เกมใช้จริงกับภาพ emulator: `ต้ ตุ สำ น้ำ ภาษา` โดยเฉพาะ (7) รายงานเฉพาะ changed IDs, หลักฐาน G0-G5, blockers, next action และอัปเดต `docs/NEXT_TASK.md`.

ห้ามพิมพ์ CSV ทั้งไฟล์ ห้ามแปล approved rows ซ้ำถ้าต้นฉบับและบริบทไม่เปลี่ยน ห้ามอ้างว่า emulator ผ่านเมื่อยังไม่ได้ทดสอบ. แพตช์ใช้ฐาน ROM ที่ตรวจ hash ตรงเท่านั้น. เมื่อไม่แน่ใจความหมาย ให้ถามหรือทำ `NEEDS_CONTEXT` แทนการเดา.
