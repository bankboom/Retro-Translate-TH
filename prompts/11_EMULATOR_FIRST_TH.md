# Codex: เอาแพตช์ไปทดสอบ Emulator ก่อน (ทุกเกม)

ใช้ Framework V3.2 โหมด **Emulator-First Fast Lane** อ่าน `AGENTS.md`, `docs/EMULATOR_FIRST_TH.md` และแค่ checkpoint ของโปรเจกต์ปัจจุบัน

**ขอผลลัพธ์เป็นแพตช์ทดสอบ 1–5 ข้อความโดยเร็วที่สุดที่พิสูจน์ความปลอดภัยได้ ไม่ใช่แปล CSV เพิ่ม**

- ตรวจ ROM/hash ที่เคยยืนยันแล้วโดยไม่สแกนใหม่เกินจำเป็น
- เลือกข้อความที่มองเห็นได้ในเมนูจากตารางที่พิสูจน์ codec/encoding/IDs แล้ว
- แก้ส่วนเล็กที่สุด เริ่มจาก in-place/fixed-size; ห้ามเขียนทับ ROM ต้นฉบับ ห้าม relocate แบบเดา; ทำ diff และ reversible test
- เมื่อสร้าง candidate ได้จริง ให้สร้าง BPS สำหรับ clean ROM ที่ตรงรุ่น พร้อม build/hash และขอทดสอบ Emulator
- ถ้ายังไม่มีฟอนต์ไทย ให้เริ่มด้วย smoke patch ตัวอักษรที่ระบบรองรับเพื่อพิสูจน์ reinjection ก่อน แล้วทดสอบฟอนต์ไทยลำดับถัดไป
- ถ้าไม่สามารถสร้าง ROM/แพตช์ที่ตรวจไบนารีผ่านได้ ให้ระบุอุปสรรค **หนึ่งข้อที่ขวางการสร้างแพตช์** แล้วแก้เฉพาะจุดนั้น อย่ากลับไปสืบสวนเหตุการณ์/ARM หรือแปลเพิ่มโดยไม่จำเป็น
- แยก `SMOKE_READY` ออกจากผล G0–G5; ไม่อ้างว่า Emulator ผ่านถ้ายังไม่มีภาพ/บันทึกทดสอบ
- ประหยัดโทเคน รายงานเฉพาะ diff, ไฟล์ใหม่, สถานะ emulator, และ next test

สำหรับ Mario Party DS USA Rev 2: คำแปลเดิม 1,336/2,672 เป็นร่าง ไม่ใช่แพตช์ ใช้เมนูที่ยืนยันแล้วเพื่อทำ candidate; ตัว relocator แบบ suffix เดิมไม่เหมาะกับ layout นี้; ห้ามให้ event 102 รายการขวาง smoke menu patch

**Context QA 6 เฟส:** อ้างอิง `docs/SIX_PHASE_CONTEXT_QA_TH.md`. ตรวจความหมาย ผู้พูด/ฉาก ภาษาไทย ศัพท์เฉพาะ ความต่อเนื่อง และ tokens/width ของข้อความแปลทุก batch ก่อนนับเป็น `REVIEWED`; ไม่ต้องตรวจคำแปลทั้งเกมก่อนทดสอบแพตช์ 1–5 ข้อความ. ข้อความที่ยังไม่รู้บริบทใช้ `NEEDS_CONTEXT`. ใน Emulator กลับมาทบทวนสำนวนจากฉากจริง และนับความคืบหน้า reviewed / injected / verified แยกกัน.
